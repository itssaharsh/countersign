# Workstream: Qodo evidence trail

- Every feature branch → PR with imperative title, what/why/how-tested description, linked issue.
- Wait for Qodo review on EVERY PR. Fix every valid High or dismiss in-thread with a reason.
- Keep a running list in docs/QODO-LOG.md: PR #, what Qodo surfaced, what we changed/dismissed.
- README `## Qodo Code Review Evidence`: link the most representative merged PR + 1-2 sentences +
  note that history shows completed review, decisions, and a follow-up review of final code.
- Final day: request a follow-up Qodo review against the final code state (re-review on last PR).
